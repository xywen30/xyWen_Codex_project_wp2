# Ozon 家居爆品趋势雷达 V2

这是一个与旧版项目并行运行的独立 V2。它不会绕过验证码、登录或反爬机制，也不会伪造销量。

## 一键运行

双击 `start.bat`。程序会先执行数据源诊断、真实公开数据发现、趋势计算、CSV 导出和健康检查；成功后启动中文 Streamlit 看板。

## 数据口径

- `REAL`：当天确实从公开网页、公开数据集或公开搜索索引观察到的数据。
- `ESTIMATED`：由排名、曝光频率、评论数变化、价格变化等公开信号计算出的趋势指标，不是成交量。
- `DEMO`：仅用于验证 15 天趋势和榜单流程的模拟数据，与真实数据严格隔离。
- 真实销量、点击量、停留时长无法从公开来源取得时，字段保持空值。

## 价格与汇率

导出和看板同时展示：卢布现价、卢布原价、人民币估算价、人民币估算原价、RUB/CNY 换算率、汇率日期与汇率来源。人民币金额是按公开汇率换算的估算值，不代表实际结算价。

## 主要目录

- `data/ozon_trend.db`：SQLite 主数据库
- `网爬结果/家居_当天日期.xlsx`：用户日常查看的统一中文 Excel（仅展示 REAL/ESTIMATED，DEMO 只用于内部测试）
- `data/exports/`：程序内部使用的 UTF-8 BOM CSV 中间文件
- `data/backups/`：数据库备份，保留最近 7 份
- `logs/`：运行、错误和诊断日志
- `reports/`：数据源诊断、运行报告、健康检查和趋势模型说明
- `config/`：关键词和趋势权重配置
- `tests/`：自动化测试

## 冷启动规则

只有 1 天真实数据时不会冒充 7 天或 15 天趋势。程序会明确显示“历史不足”，继续每天运行即可积累快照。演示数据可独立验证完整 15 天计算链路。

## 2026-08-19 增量功能

- 十个家居一级类目的关键词矩阵和采集覆盖诊断。
- 20 个唯一商品的 REAL 潜力榜。
- 基于评论总数公开快照的评论热度预分析；该指标不是销量。
- Streamlit 商品检索与多条件筛选。
- Excel 新增 `评论热度预分析` 和 `家居类采集诊断`，仍不展示 DEMO。
